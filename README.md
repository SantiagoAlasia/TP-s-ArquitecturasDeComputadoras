# TP-s-Arquitecturas de Computadoras

Repositorio de trabajos prácticos para la materia **Arquitecturas de Computadoras**.

## 📋 Descripción

Este proyecto contiene los trabajos prácticos desarrollados como parte del curso de Arquitecturas de Computadoras. Los ejercicios cubren conceptos fundamentales y avanzados del diseño y funcionamiento de sistemas computacionales.
